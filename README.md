# Single-Step QSM with Total Generalized Variation Regularization

MATLAB code and a numerical brain phantom for single-step QSM with variational (TV and TGV) penalties, compared with multi-step reconstructions.

## Usage

Run `script_brain_phantom.m` from the repository folder in MATLAB.

## Reference
